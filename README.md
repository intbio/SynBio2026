Selection of thermostable GFP variants
Candidate GFP mutant sequences were obtained from a library of high-brightness variants and used as input for thermostability prediction. The first 10,000 protein sequences were exported to FASTA format and analyzed using the PPtStab framework to estimate protein melting temperature (Tm) [10.1038/s41598-025-98667-9]. Predictions were generated using multiple feature representations, including sequence-based (SER), amino acid composition (AAC), and embedding-based (EMB) models.
For each sequence, additional physicochemical descriptors were calculated using the ProteinAnalysis module from Biopython. These descriptors included molecular weight, aromaticity, instability index, isoelectric point, GRAVY (grand average of hydropathy), predicted secondary structure fractions (helix, turn, and beta-sheet), amino acid composition, and sequence length.
Deep protein sequence embeddings were generated using the pretrained ESM-2 protein language model  implemented in the Hugging Face Transformers library. Mean-pooled hidden representations were extracted for each sequence and appended to the feature set.
A binary classification dataset was constructed using experimentally measured functional thermostability values [10.1038/s41467-023-38099-z]. Variants with functional thermostability above 72°C were assigned to the thermostable class, while the remaining variants were assigned to the non-thermostable class.
The training feature matrix consisted of PPtStab-predicted melting temperatures, physicochemical descriptors, amino acid composition, sequence length, and ESM-2 embeddings [10.1101/2022.12.21.521521]. Sequence identifiers and raw amino acid sequences were excluded from model training.
Several ensemble machine learning models were evaluated, including Gradient Boosting and Extremely Randomized Trees (ExtraTrees). The dataset was divided into training and test subsets using a stratified 75:25 split to preserve class proportions. Model performance was assessed on the held-out test set using standard classification metrics.
The final screening model was an ExtraTrees classifier comprising 1,500 decision trees. The trained classifier was applied to the candidate GFP variants to estimate the probability of belonging to the thermostable class. Variants were ranked according to their predicted probability, and the highest-scoring candidates were selected as putative thermostable GFP mutants for downstream experimental validation.
